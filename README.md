# Blood Bank Management System

## 📌 Project Overview
The Blood Bank Management System is a web-based application developed as a Bachelor's final year project.  
It is designed to manage blood stock, donor details, and blood requests efficiently with an admin-controlled approval process.

---

## 🎯 Objectives
- To digitize blood bank operations
- To manage blood availability securely
- To prevent incorrect stock reduction
- To provide admin verification for blood requests

---

## ⚙️ Key Features
- Donor registration and management
- Blood request by recipients
- Admin approval or rejection of requests
- Blood stock updates only after admin confirmation
- Secure and structured database handling

---

## 🧠 System Workflow
1. Recipient submits a blood request  
2. Request is stored in the database  
3. Admin reviews the request  
4. If approved → blood stock is reduced  
5. If rejected → request is removed  

---

## 🛠️ Technologies Used
- **Frontend:** HTML,CSS,JavaScript  
- **Backend:** Java
- **Database:** MySQL  
- **Tools:** eclipse
